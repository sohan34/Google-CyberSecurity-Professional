
# 🛠️ Module 4: Security Tools & Portfolio

## 📖 Overview

An entry-level security analyst uses various tools to monitor systems, investigate incidents, automate tasks, and document their work. Organizations may use different tools depending on their security needs, but understanding industry-standard tools is essential.

---

# 🧰 Entry-Level Analyst's Toolkit

## Security Information and Event Management (SIEM)

A **SIEM** is an application that **collects and analyzes log data** to monitor security events and detect threats.

### Features

- Collects logs from multiple systems
- Analyzes security events
- Generates alerts for threats and vulnerabilities
- Uses dashboards to visualize security data

> **Note:** SIEM solutions can be **cloud-hosted** or **on-premises**.

---

## Network Protocol Analyzer (Packet Sniffer)

A **packet sniffer** captures and analyzes network traffic.

### Purpose

- Monitor network communication
- Capture packets for analysis
- Investigate suspicious network activity

---

# 📘 Playbooks

A **playbook** is a documented guide that outlines procedures for handling specific security tasks or incidents.

Its purpose is to help analysts respond consistently by following predefined steps.

---

## Chain of Custody Playbook

**Chain of custody** is the process of documenting the possession and handling of digital evidence throughout an investigation.

### It records:

- Who handled the evidence
- What evidence was collected
- Where it was stored
- Why it was accessed

Maintaining proper chain of custody ensures evidence remains reliable for investigations.

---

## Protecting & Preserving Evidence

Digital evidence can be **fragile** or **volatile**, so it must be preserved correctly.

### Best Practices

- Preserve evidence before analysis
- Create copies of evidence
- Investigate using the copied data
- Avoid altering the original evidence

### Order of Volatility

The **order of volatility** prioritizes data that should be preserved first because it may be lost if a system powers off.

# 💻 Programming

Programming helps automate repetitive security tasks.

## Python

Used for:

- Automation
- Scripting
- Reducing manual work
- Minimizing human error

---

## SQL (Structured Query Language)

SQL is used to:

- Create databases
- Query information
- Update and manage stored data

### Database

A **database** is an organized collection of information.

A **data point** is an individual piece of information stored in a database.

---

# 🖥️ Operating Systems

An **operating system (OS)** acts as the interface between users and computer hardware.

Common operating systems include:

- Linux
- Windows
- macOS

---

## Linux

Linux is an **open-source operating system**.

### Features

- Publicly available source code
- Uses a **Command-Line Interface (CLI)**
- Commands are used to interact with the system

> **Note:** Linux is an operating system, **not** a programming language.

---

# 🌐 Web Vulnerabilities

A **web vulnerability** is a weakness in a web application that attackers can exploit.

Possible impacts include:

- Unauthorized access
- Data theft
- Malware deployment

> The **OWASP Top 10** lists the most critical web application security risks.

---

# 🦠 Antivirus Software

Antivirus software helps:

- Prevent malware infections
- Detect malware
- Remove malware and viruses

It scans system memory and files for malicious patterns.

---

# 🚨 Intrusion Detection System (IDS)

An **IDS** monitors system and network activity for suspicious behavior.

### Functions

- Monitors network packets
- Detects unauthorized access
- Alerts security teams about possible intrusions

---

# 🔐 Encryption

Encryption protects data by converting readable information (**plaintext**) into unreadable **ciphertext**.

### Purpose

- Protect confidentiality
- Prevent unauthorized access

> **Encoding vs Encryption**
>
> - **Encoding:** Changes data format for compatibility.
> - **Encryption:** Protects data using cryptographic methods.

---

# 🎯 Penetration Testing

**Penetration testing (Pen Testing)** is a simulated cyberattack used to identify vulnerabilities.

### Benefits

- Finds security weaknesses
- Evaluates system defenses
- Improves overall security

# 📝 Key Takeaways

- **SIEM** tools collect and analyze log data to detect security events.
- **Packet sniffers** capture and analyze network traffic.
- **Playbooks** provide standardized procedures for responding to incidents.
- **Chain of custody** ensures digital evidence remains trustworthy.
- **Order of volatility** prioritizes preserving the most fragile data first.
- **Python** is commonly used for automation, while **SQL** manages databases.
- **Linux** is an open-source operating system that uses a command-line interface.
- **IDS** monitors systems for suspicious activity.
- **Encryption** protects data confidentiality by converting plaintext into ciphertext.
- **Penetration testing** identifies vulnerabilities through simulated attacks.
- A well-organized **portfolio** demonstrates practical cybersecurity skills to employers.
